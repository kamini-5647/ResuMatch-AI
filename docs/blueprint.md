# **App Name**: ResuMatch AI

## Core Features:

- Intelligent Resume Parser: An AI-powered extraction tool that identifies key skills, experience, and contact details from PDF and DOCX uploads with high precision.
- Smart ATS Scoring Tool: Utilizes AI to reason across job descriptions and resumes, providing a detailed ATS compatibility score and improvement checklist.
- Real-time Analytics Dashboard: Interactive data visualizations using Recharts to track skill distributions, keyword optimization, and resume strength trends.
- Job Match & Recommendation Tool: AI-driven recommendation engine that uses context to match users with roles from the dashboard based on their current resume strength.
- Universal File Uploader: Responsive drag-and-drop zone with immediate file preview and dynamic progress indicators using Framer Motion.
- Secure Profile & Career Archive: Persistence of user data including resume versions and job bookmarks in a centralized relational database.
- Theme-Responsive Glassmorphism UI: A polished professional interface featuring light/dark mode support and seamless navigational transitions.

## Style Guidelines:

- Primary Color: Royal Blue (#3B58E6), representing trust and professional stability.
- Background Color: Sophisticated Sky Gray (#F8F9FD), a slightly tinted, airy light scheme color.
- Accent Color: Azure Blue (#3BAEE6), analogous and slightly shifted hue for distinct secondary buttons and interactive states.
- Font pairing: 'Poppins' for high-end, geometric headlines and 'Inter' for crisp, machined, objective body text.
- Lucide React icons set with thin-stroke styling for a minimalist, modern agency look.
- Modular grid system with high-contrast sections and generous white space to enhance focus and content hierarchy.
- Graceful entrance transitions and micro-interactions for upload components using Framer Motion.
